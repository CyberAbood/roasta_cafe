# ROASTA Coffee: digital menu (demo)

Static bilingual menu (Arabic/English) by [BaristaWeb](https://www.baristaweb.studio). No backend, cookies, trackers or third-party requests.

## Publish
1. Create a public repository named exactly `roasta-menu` on the `CyberAbood` account.
2. Upload the contents of this folder to the repository root.
3. Settings > Pages > Source: **Deploy from a branch** > `main` / `(root)`.
4. Open https://cyberabood.github.io/roasta-menu/ and scan `qr/roasta-menu-qr.png`.

## Edit
All items and prices live in `assets/js/menu-data.js`.

## Before going live
- This is a demo until the café approves it: remove the "demo" wording in `index.html` and `assets/js/app.js`, the `noindex` tag and the `Disallow` in `robots.txt`.
